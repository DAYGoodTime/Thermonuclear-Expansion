# 未来可实现的机制


### 1.新增流体

钾钠合金与超级冷却液的复合路线已实现原型：冷／热流体、混合机制造、核电站供热、热交换站超超临界产汽；当前规则及验证边界见[钾钠合金复合冷却液](../docs/wiki/fluids/钾钠合金复合冷却液.md)。不将“混所有冷却液”视为已确认要求。

### 2.新增增殖输入口与增殖输出口

- [ ] 新增增殖输入口，支持输入增殖燃料棒。
- [ ] 新增增殖输出口，支持输出增殖燃料棒。

### 3.新增反应堆访问接口

- [ ] 新增反应堆访问接口，支持从反应堆中取出尚未使用完的燃料棒，禁止通过该接口放入燃料棒。

### 4.新增堆芯融毁机制

- [ ] 反应堆热量超过上限时不再自动停机；热量持续超过上限 10 秒后触发堆芯融毁，将反应堆中的燃料棒方块替换为岩浆方块。
