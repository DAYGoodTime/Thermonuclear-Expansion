# GTNH 蒸汽发电扩展模组规划

## 1. 项目定义

### 1.1 项目目标

本模组面向 GTNH 2.9.0 的 EV 及以后阶段，目标是解决现有蒸汽发电路线吞吐量不足、发电能力偏弱、规模化收益较低的问题。

模组不创建脱离 GTNH 资源体系的新能源体系，而是扩展多种冷却液、IC2 热冷却液和蒸汽发电路线，并增加一台使用燃料棒的核电站主机，使其能够从 EV 一直使用到终局阶段。

### 1.2 核心流程

```text
IC2 热冷却液 + IC2 蒸馏水
-> 多方块热交换站
-> 普通蒸汽 / 过热蒸汽 / 超临界蒸汽 / 超超临界蒸汽
-> 大型蒸汽涡轮机 / 超超临界蒸汽涡轮机
-> 电力
```
核电路线：

```text
蒸馏水 / IC2 冷却液 / 超级冷却液 / 二级纯净水 + 燃料棒 + 主控电路板
-> 核电站主机
-> 对应热流体或高压高温流体
```

热交换完成后返还冷却液，使冷却液能够回到原有循环中。

### 1.3 内容边界

本模组只规划四台新增多方块机器：

1. 多方块热交换站。
2. 大型蒸汽涡轮机。
3. 超超临界蒸汽涡轮机。
4. 核电站主机。

明确不包含：

- EV 之前的蒸汽发电平衡调整。
- 燃油、太阳能、熔盐、氦或等离子等其他能源路线。
- 温度数值、温差、升温过程或温度故障系统。
- 热缓冲或蓄热系统。
- 新增单方块热交换机或单方块涡轮机。
- 独立于核电站主机之外的单方块核反应设备。
- 普通、过热和超临界蒸汽各自独立的涡轮控制器。

## 3. GTNH 现有基准

### 3.1 极热交换机基准配方

根据 GTNH 2.9.0 相关 Good Generator 实现，IC2 热冷却液配方的标称数据为：

| 项目 | 数值 |
| --- | ---: |
| 输入 IC2 热冷却液 | 16,000 L |
| 输入 IC2 蒸馏水 | 20,000 L |
| 输出 IC2 冷却液 | 16,000 L |
| 超临界蒸汽输出 | 32,000 L |
| 过热蒸汽标称输出 | 3,200,000 L |
| 单次运行时间 | 20 tick |
| 内部处理功率基准 | 160,000 EU/t |
| 超临界蒸汽能量价值 | 100 EU/L |

### 3.2 输出逻辑说明

极热交换机不会在一次运行中同时输出过热蒸汽和超临界蒸汽：

- 热冷却液消耗量达到转换阈值时，输出超临界蒸汽。
- 未达到转换阈值时，输出过热蒸汽。
- 过热蒸汽的实际输出随热冷却液消耗量按比例变化。

这些数值用于建立本模组的平衡基线，不代表新增机器必须直接复制相同配方。

## 4. 多方块热交换站

### 4.1 定位

多方块热交换站是本模组唯一新增的热交换设备。它从 EV 阶段开始使用，固定结构即可支持所有规划中的热流体和蒸汽等级。除 IC2 热冷却液外，它还支持核电站主机产生的热超级冷却液和超高压高温纯净水等热流体。

主要目标：

- 提高 IC2 热冷却液的处理吞吐量。
- 减少大规模蒸汽生产所需的机器数量和占地。
- 为四种蒸汽提供统一、可升级的生产设备。
- 保持与 IC2 冷却液循环兼容。

### 4.2 输入与输出

输入：

- IC2 热冷却液 `ic2hotcoolant`。
- 热超级冷却液。
- 超高压高温纯净水。
- IC2 蒸馏水 `ic2distilledwater`。

输出：

- 与输入热流体对应的冷却液或工作流体。
- 当前结构配置对应的一种蒸汽。

运行限制：

- 同一运行周期只能处理一种热流体，并只能输出一种对应蒸汽。
- 不允许通过混合配置同时获得多种蒸汽。
- 不同热流体不得互相替代或合并计算能量价值。
- 输出堵塞时必须停止运行，不得丢失或复制流体。

### 4.3 固定结构

热交换站不设置结构升级、内部核心替换或阶段性结构解锁。建成固定结构后，即可根据输入热流体和工作流体使用对应配方，输出允许的蒸汽或后续工作流体。

不同热流体和蒸汽等级的差异通过配方、流量、处理时间和配置参数体现，不通过更换结构部件体现。

## 5. 蒸汽能量价值

| 蒸汽类型 | 能量价值 | 相对普通蒸汽 | 发电设备 |
| --- | ---: | ---: | --- |
| 普通蒸汽 | 0.5 EU/L | 1 倍 | 大型蒸汽涡轮机 |
| 过热蒸汽 | 1 EU/L | 2 倍 | 大型蒸汽涡轮机 |
| 超临界蒸汽 | 100 EU/L | 200 倍 | 大型蒸汽涡轮机 |
| 超超临界蒸汽 | 500 EU/L | 1,000 倍 | 超超临界蒸汽涡轮机 |

超超临界蒸汽必须由安装终局核心的多方块热交换站直接生产，不能通过简单压缩或按比例消耗超临界蒸汽获得。

## 6. 大型蒸汽涡轮机

### 6.1 定位

大型蒸汽涡轮机是一台从 EV 使用到后期的多方块发电设备，统一处理：

- 普通蒸汽。
- 过热蒸汽。
- 超临界蒸汽。

不为这三种蒸汽分别增加独立机器。

### 6.2 运行规则

- 根据输入蒸汽种类自动使用对应能量价值。
- 同一运行周期只允许处理一种蒸汽。
- 混入其他蒸汽时不得叠加倍率或产生额外收益。
- 转子决定基础效率和最佳流量。
- 发电仓和结构等级限制最大输出。
- 实际流量偏离最佳流量时降低发电效率。

### 6.3 维护规则

- 必须安装维护仓。
- 使用 GTNH 标准多方块维护机制。
- 不需要润滑油。
- 不消耗润滑油。
- 维护状态异常时降低效率或停止运行。

## 7. 超超临界蒸汽涡轮机

### 7.1 定位

超超临界蒸汽涡轮机是独立的终局多方块发电设备，只处理超超临界蒸汽。

### 7.2 运行规则

- 只接受超超临界蒸汽。
- 拒绝普通蒸汽、过热蒸汽和超临界蒸汽。
- 按 500 EU/L 的基础能量价值计算。
- 使用专用高等级转子和超高压输入仓。
- 使用高等级发电仓输出电力。
- 实际流量偏离最佳流量时，效率惩罚高于大型蒸汽涡轮机。

### 7.3 维护与润滑规则

- 必须安装维护仓。
- 使用 GTNH 标准多方块维护机制。
- 必须持续供应润滑油。
- 润滑油不足时立即停止运行。
- 不允许在无润滑状态下继续发电或降级运行。
- 润滑油消耗量应与实际蒸汽流量或发电功率关联。
- 维护状态异常时降低效率或停止运行。

润滑油仅用于超超临界蒸汽涡轮机，不影响大型蒸汽涡轮机。

## 8. 核电站主机

### 8.1 定位

核电站主机是一台独立的多方块核能设备。它使用燃料棒产生电力，并根据输入冷却液类型输出对应的热流体或高压高温流体。不同输出可以分别接入蒸汽涡轮机、热交换站或其他后续处理设备。

核电站主机不接受蒸汽或其他核燃料流体作为替代输入。使用蒸馏水时，主机直接输出过热蒸汽。

### 8.2 输入与输出

输入：

- 蒸馏水。
- IC2 冷却液 `ic2coolant`。
- 超级冷却液。
- 二级纯净水。
- GTNH 可用的核燃料棒，具体燃料棒列表由配方配置确定。
- 主控电路板，安装在主机控制器的电路板槽位中。

输出：

- 电力。
- 使用蒸馏水时输出过热蒸汽。
- 使用 IC2 冷却液时输出 IC2 热冷却液 `ic2hotcoolant`。
- 使用超级冷却液时输出热超级冷却液。
- 使用二级纯净水时输出超高压高温纯净水。

运行限制：

- 冷却液不足时不得继续消耗燃料棒。
- 对应输出流体堵塞时必须停止反应和发电，不得丢失流体或燃料。
- 同一运行周期只允许使用一种冷却液，不允许混合不同冷却液计算倍率。
- 冷却液类型决定输出流体、单位输入量、发电效率、燃料消耗和输出产出，具体数值由配置文件确定。
- 同一运行周期只处理一种燃料棒。
- 燃料棒必须按完整物品堆栈和耐久规则处理，区块卸载或服务器重启不得复制、回滚或丢失燃料状态。

### 8.3 主控电路板

主控电路板用于控制核电站主机的工作效率。电路板不是装饰物或普通启动材料，而是机器运行所需的核心配置部件。

电路板档位至少包括：

| 电路板档位 | 作用 |
| --- | --- |
| 基础主控电路板 | 提供基础发电效率、燃料消耗和输出流体产出 |
| 高效主控电路板 | 提高发电效率，降低单位电力的燃料消耗，并按配置提高输出流体产出 |
| 超高效主控电路板 | 提供最高效率，但需要更高阶段材料或更高机器等级 |

电路板属性应同时影响：

- 基础发电效率。
- 燃料棒消耗速率或单根燃料棒的有效运行时间。
- 冷却液类型和消耗速率。
- 当前输出流体的产出速率。
- 机器允许的最大功率输出。

电路板不得凭空增加燃料棒总能量。效率提升只能减少单位产出的资源消耗、提高可用能量利用率或改善输出流体产出比例，并应在配置文件中保留可调整参数。

### 8.4 运行与安全规则

- 核电站主机必须同时检查燃料棒、冷却液、电力输出和对应输出流体状态。
- 任意必要输入不足或任意输出堵塞时，机器安全停止。
- 维护仓故障时停止运行或按 GTNH 标准维护机制降低效率，不得跳过维护条件。
- 不引入温度数值、温差计算或额外的熔毁事件系统。
- 输出流体仅作为受控输出，不设置无冷却液时继续发电的缓冲发电模式。
- 核电站主机产生的电力不能绕过发电仓、能源仓或结构等级限制。

### 8.5 界面信息

应显示：

- 当前燃料棒种类、剩余耐久或剩余运行时间。
- 当前冷却液类型、库存和消耗速率。
- 当前输出流体类型、库存和产出速率。
- 当前电路板档位及效率倍率。
- 当前 EU/t、最大 EU/t 和实际燃料消耗。
- 电路板、燃料、冷却液或输出堵塞导致的停机原因。

## 9. 阶段规划

| 阶段 | 新增能力 | 阶段目标 |
| --- | --- | --- |
| EV | 核电站主机、基础主控电路板、固定结构热交换站、大型蒸汽涡轮机、普通蒸汽 | 建立可规模化的核能供热和蒸汽发电闭环 |
| IV | 过热蒸汽及对应配方 | 提高流体吞吐量和发电密度 |
| LuV-ZPM | 超临界蒸汽及对应配方 | 支撑后期大型工业用电 |
| UV 及以后 | 超超临界蒸汽涡轮机、超高效主控电路板及对应配方 | 提供终局高密度蒸汽发电和核能输出 |

## 10. 平衡原则

### 10.1 总体原则

- 蒸汽路线从 EV 开始必须具备长期使用价值，而不是备用电源。
- 平衡完整电站的造价、占地、流体吞吐量和持续输出，不只比较单台机器的 EU/t。
- 高阶段升级应改善吞吐量、空间效率或发电能力中的至少一项。
- 不通过增加无关能源路线制造选择复杂度。

### 10.2 防止能量复制

- 热交换站不得凭空增加蒸馏水、冷却液或蒸汽。
- 核电站主机不得凭空增加燃料棒能量、冷却液或对应输出流体。
- 不同蒸汽之间的转换不得产生额外能量。
- 主控电路板只能改变效率、消耗和输出参数，不得绕过燃料棒或冷却液输入条件。
- 大型蒸汽涡轮机必须按实际输入蒸汽使用对应能量价值。
- 混合蒸汽不得绕过机器限制或发电倍率。
- 超超临界蒸汽不得由低成本流体直接转换获得。

### 10.3 超超临界路线平衡

超超临界蒸汽保持 500 EU/L，不通过降低单位能量价值进行平衡。主要成本来自：

- 固定结构热交换站及其对应的终局流体配方。
- 独立的超超临界蒸汽涡轮机。
- 专用转子和超高压输入仓。
- 更严格的最佳流量要求。
- 持续润滑油消耗。
- 更高等级的发电仓和结构材料。

## 11. 界面与状态信息

### 11.1 多方块热交换站

应显示：

- 热冷却液输入量和消耗速率。
- 蒸馏水输入量和消耗速率。
- 冷却液输出量。
- 当前蒸汽输出种类和产量。
- 当前热流体配方和处理上限。
- 输出堵塞或输入不足状态。

### 11.2 两类涡轮机

应显示：

- 当前蒸汽种类。
- 实际流量和最佳流量。
- 当前 EU/t 和最大 EU/t。
- 当前发电效率。
- 转子状态。
- 维护状态。
- 停机原因和输出受限原因。

超超临界蒸汽涡轮机额外显示：

- 润滑油库存。
- 润滑油消耗速率。
- 因润滑油不足而停机的状态。

### 11.3 核电站主机

应显示：

- 当前燃料棒种类、剩余耐久或剩余运行时间。
- 当前冷却液类型、库存和消耗速率。
- IC2 热冷却液库存和产出速率。
- 当前主控电路板档位及效率倍率。
- 当前 EU/t、最大 EU/t 和实际燃料消耗。
- 燃料、冷却液、电路板或输出堵塞导致的停机原因。

## 12. 待确定数值

以下内容尚未确定，应在原型测试后定案：

- 固定结构热交换站各流体配方的最大吞吐量。
- 四种蒸汽对应的热冷却液与蒸馏水配比。
- 热交换站支持的热超级冷却液、超高压高温纯净水配方及对应输出流体。
- 两台涡轮机支持的转子材料和转子属性范围。
- 大型蒸汽涡轮机的流量偏离惩罚。
- 超超临界蒸汽涡轮机的流量偏离惩罚。
- 超超临界蒸汽涡轮机的润滑油种类。
- 润滑油消耗公式和最低缓存量。
- 各阶段允许使用的发电仓等级和最大输出。
- 核电站主机支持的燃料棒列表、燃料棒消耗公式和对应输出流体产出比例。
- 蒸馏水、IC2 冷却液、超级冷却液和二级纯净水各自的输出流体、效率、消耗和产出倍率。
- 各档主控电路板的效率、功率、燃料消耗和冷却液消耗倍率。
- 四台多方块机器的具体结构、尺寸和最低外壳数量；热交换站不设结构升级。

## 13. 验收与测试

### 13.1 功能验收

- 热交换站正确消耗 IC2 热冷却液、热超级冷却液或超高压高温纯净水及对应工作流体，并按配方输出对应流体。
- 热交换站对不同热流体使用各自配方和产出规则，不混合流体或套用错误倍率。
- 同一运行周期只生产一种蒸汽。
- 输入不足或输出堵塞时机器安全停止。
- 大型蒸汽涡轮机正确识别普通、过热和超临界蒸汽。
- 大型蒸汽涡轮机不接受超超临界蒸汽。
- 超超临界蒸汽涡轮机只接受超超临界蒸汽。
- 两台涡轮机都正确响应维护仓故障。
- 大型蒸汽涡轮机在没有润滑油时正常运行。
- 超超临界蒸汽涡轮机在润滑油不足时立即停止。
- 核电站主机正确消耗燃料棒和所选冷却液，并输出电力和对应流体。
- 蒸馏水输出过热蒸汽，IC2 冷却液输出 IC2 热冷却液，超级冷却液输出热超级冷却液，二级纯净水输出超高压高温纯净水。
- 蒸馏水、IC2 冷却液、超级冷却液和二级纯净水均按各自配置参数运行。
- 核电站主机拒绝混合冷却液输入，且冷却液类型切换不会复制或损失流体。
- 核电站主机正确读取主控电路板，并应用对应效率、消耗和产出参数。
- 核电站主机在燃料、冷却液不足或对应输出流体堵塞时立即停止。

### 13.2 数值验收

- 普通蒸汽按 0.5 EU/L 基准计算。
- 过热蒸汽按 1 EU/L 基准计算。
- 超临界蒸汽按 200 EU/L 基准计算。
- 超超临界蒸汽按 600 EU/L 基准计算。
- 混合流体、机器串联和冷却液循环不会产生能量复制。
- EV 阶段整套蒸汽电站相较现有路线具备明确的吞吐量或空间优势。
- 后续升级相较前一阶段具有可量化收益。
- 不同主控电路板及冷却液类型组合下的单位燃料产出、冷却液消耗和对应输出流体产出符合配置值。

### 13.3 稳定性验收

- 服务器重启后正确恢复流体、转子、维护和润滑油状态。
- 区块卸载和重新加载不会复制或丢失流体。
- 多台机器长期运行不会产生明显内存增长。
- 大规模电站不会对服务器 TPS 造成不可接受的影响。

## 14. 首发范围

首发版本包含：

- 1 台固定结构的多方块热交换站，支持所有规划中的热流体及蒸汽配方。
- 1 台大型蒸汽涡轮机。
- 1 台超超临界蒸汽涡轮机。
- 1 台核电站主机。
- 基础、高效和超高效主控电路板的配置接口。
- 普通、过热、超临界和超超临界蒸汽支持。
- 维护仓支持。
- 超超临界蒸汽涡轮机的润滑油消耗。
- GUI 状态信息。
- NEI 配方展示。
- 平衡配置文件。
- 单机和多人服务器测试。

首发版本不加入温度系统、蓄热模块、额外独立核反应设备、多能源路线或额外单方块机器。
