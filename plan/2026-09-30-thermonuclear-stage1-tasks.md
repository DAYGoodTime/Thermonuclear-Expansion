## 使用边界

本文保留 **2026-09-30 首轮范围与任务依赖**，不是当前未完成清单；后续确认和源码已改变部分初始设计。当前入口、配置与行为见[项目知识库](../docs/wiki/development/项目知识库.md)和[原型指南](../docs/wiki/development/第一阶段原型开发指南.md)，逐次结果见[开发验证记录](../docs/开发验证记录.md#2026-09-30)。不据文中的原要求回退现有实现，也不自动解决产品规划冲突。

首轮目标是三台创造模式原型：核电站、固定结构热交换站、大型普通蒸汽涡轮机。该交付轮只要求 Wrapper `compileJava processResources`，不开设 `src/test/`、不执行测试／完整发布构建／游戏／性能／整合包验收；后来其他轮次的测试与构建另记，不覆盖首轮验证范围。原计划编写轮未改源码或执行构建。

## 首轮确认的行为

| 设备 / 主题 | 初始要求 |
| --- | --- |
| 核电站 | 通过普通物品输入接收经核验的 IC2／GT 有效燃料，按属性和寿命处理，不模拟布局；同周期一种燃料／冷却液。模式用可扩展枚举／策略，不用布尔开关 |
| 直接发电 | 不需要或消费冷却液，正常消耗燃料，初定较低效率并启动爬升；要求发电仓 |
| 供热 | IC2／超级冷却液→对应热流体，不发电；初定燃料、冷却液和热输出同倍率爬升，冷却液数量配对 |
| 模式切换／乏燃料 | 停机时服务端校验切换，保留寿命和余量；耗尽生成对应乏燃料，出口堵塞保留待排物品，不混用整堆耐久、不复制产物 |
| 热交换 | 固定结构、无启动、无升级核心；两种热冷却液各配蒸馏水，完整返还对应冷却液；初定只出普通蒸汽，水汽转换按 GT `STEAM_PER_WATER=160`；一次一种配方，不合并热流体核算 |
| 普通蒸汽涡轮 | GT 转子，有界吞吐与效率强化，不改转子全局属性、取消最佳流量惩罚；转子与发电仓共同限额，按实际蒸汽量核算，启动只降低电力；160 L 蒸汽回收 1 L 蒸馏水，余量存档，回收不爬升 |
| 启停与输出 | 核电／涡轮独立保存启动／衰减配置；拆除或真正换转子清零，磨损不算换转子，重载保留。电力送不出仍消耗、作废、不补发；流体堵塞零消费、联合检查所有输出后提交；小数累计避免逐 tick 取整失真 |
| 结构与维护 | 初定三台立方体空腔、标准外壳可替换相关 GT 仓室；核电需物品 IO 与模式相应流体／发电通路，热交换需流体 IO，涡轮需流体 IO／发电仓／转子。不要求维护仓，关闭父类维护但保留 GT 组件磨损 |

首轮不做：生存配方／最终材料与平衡、自定义 NEI 页面、高等级蒸汽／终局涡轮、电路板物品或槽位、温度／热缓存／邻接／反射／熔毁、独立冷凝器、GTNL 依赖／自有仓室／无线能源／全量基类。后续加入热缓存、反射规则、高等级换热输出等，不代表这些原排除项从未存在。

## 首轮参考与 API 核验

GTNL 只读参考路径相对 `src/main/java/com/science/gtnl/`，实际后续检索规则见 [GTNL 索引](../docs/wiki/references/GT-Not-Leisure参考索引.md)：

| 入口 | 初次参考用途 / 不迁入部分 |
| --- | --- |
| `loader/MachineLoader.java` | 构造／引用注册；不复用 ID 或物品枚举 |
| `common/machine/multiblock/NuclearReactor.java`、`common/item/items/fuelRod/FuelRod.java` | 燃料属性、耐久、乏燃料、启动与自定义组件差异；不迁入布局／温度／缓冲／专用仓室或自有燃料 |
| `common/machine/basicMachine/SteamTurbine.java`、`common/machine/multiblock/SiphonTurbine.java` | 蒸汽识别、仓室、NBT、送电案例；不迁入单方块、无线蒸汽、倍率或直接储能算法 |
| `common/machine/multiMachineBase/MultiMachineBase.java`、`common/gui/modularui/NuclearReactorGui.java` | 父类维护链、服务端同步；不迁入整套基类、依赖及布局 GUI |
| 资源 `assets/sciencenotleisure/lang/zh_CN.lang` | 语言键组织，不复制键或资源 |

当时 GTNL 声明 `.183`，本项目读取 GT5U `.133` sources，对燃料／转子同时用同版 dev JAR `javap` 核验：

- `ItemRadioactiveCellIC` 提供 cell 数、能量、热量、乏燃料及父类耐久 API；`IReactorComponent` 并非通用燃料属性接口。
- `TurbineStatCalculator` 提供效率／流量／耐久；`MTELargeTurbineSteam` 使用 160:1 冷凝。
- `WerkstoffMaterialPool.HotSuperCoolant` 已有，材料 API 及热／冷转换用例可查，不猜注册名。
- `doRandomMaintenanceDamage()` 同时处理维护与转子；`addEnergyOutputMultipleDynamos()` 超额可爆炸，提交前限额；结构错误接口须按具体父类核签名。

首轮仅定位独立 IC2 `.827` 缓存，尚未完成准确制品核验；当时 Context7 CLI 未安装且未增装。该历史限制不替代知识库后来确认的 IC2 替换制品。未复制 GTNL 代码／资源，复制前仍须核对 LGPL 及文件来源。

## 完成与回退边界

首轮完成标准是交付代码／资源、批准 ID 接入、编译／资源任务通过且如实记录未验证项；守恒、停机、切换、重载、长期运行与兼容仍需独立游戏验收。`test NO-SOURCE` 不算测试通过，其他阶段的 `build` 不替代本轮结果。

规划中的高端蒸汽／终局核心冲突由用户定案；原型数值集中配置、不宣传为最终平衡。回退须检查后续用户修改，仅处理对应新增入口／文件，不做全库重置或广泛删除；测试存档与删除模组后的兼容需另行处理。
