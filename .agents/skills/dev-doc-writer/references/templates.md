# 文档模板

所有模板中的 `{git user.name}` 通过 `git config user.name` 获取，获取失败则留空。

## 需求文档模板

```markdown

> 创建日期: YYYY-MM-DD HH:mm
> 作者: {git user.name}
> 状态: 草稿

- [ ] 功能点 1

- 异常情况 1 → 预期处理方式
```

## README.md 索引模板

首次初始化时创建 `{DOC_ROOT}/README.md`：

```markdown
# [项目名] — 项目文档中心

## 目录结构

{DOC_ROOT}/
├── README.md              ← 你在这里（文档入口）
├── _templates/            ← 文档模板（新建文档时复制使用）
├── assets/                ← 图片、截图、架构图等资源文件
├── conventions/           ← 开发规范、用户习惯、备忘录
├── features/              ← 功能文档（按功能聚合，日期编号排序）
│   └── YYYY-MM-DD-功能名/
│       ├── 1-需求.md
│       ├── 2-设计-标题.md
│       ├── 3-实现.md
│       ├── 4-内容变更说明.md
│       └── 参考/
│           └── 100-接口调研.md
├── adr/                   ← 架构决策记录（跨功能的技术决策）
├── wiki/                  ← 项目 Wiki（规范、指南、FAQ）
└── archive/               ← 归档（保持原分类结构）
```
