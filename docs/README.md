核电站、热交换站和大型蒸汽涡轮机已有原型代码，三种主机均已有 LV 组装机配方，耗时 10 秒，产出 1 个主机：

- 核电站：32 个 IC2 核反应堆、64 个防爆石和 64 个核反应仓。
- 热交换站：16 个大型热交换机、64 个脱氧钢外壳、64 个青铜管道方块和 6 个 IC2 高级热交换器。
- 大型蒸汽涡轮机：64 个 GT5U 当前版大型蒸汽涡轮、64 个脱氧钢机械方块和 64 个钢齿轮。

安全壳机械方块已注册，引用 GT 防爆石材质；化学浸洗槽配方为 1 个钢框架、9 个致密铅板及 144 L 混凝土，耗时 10 秒、4 EU/t，产出 1 个方块。配方注册及游戏内选择行为待验收，详见[项目知识库](wiki/development/项目知识库.md)。

增殖输入／输出总线均通过 HV 组装机制造：8 个 GT 空燃料棒、1 个 HV 机器外壳（`ItemList.Hull_HV`）、8 个钍板，耗时 100 ticks（5 秒），产出 1 个总线。输入总线使用编程电路 1，输出总线使用编程电路 2，电路不消耗；总线与螺丝刀可在合成台无序合成，双向转换输入／输出类型。

配方入口为 `RecipeLoader.registerBreederBusRecipes()`，沿用 load-complete 注册。GTNL 侧参考做法见[参考索引](wiki/references/GT-Not-Leisure参考索引.md#配方注册)；API 按当前 GT5U `.205` 核对，不迁入参考库的自有配方工具类或工具箱扩展。

燃料棒方块已有组装机配方，等级决定核电热容量与单批最大并行，电源面板分别限制各新批次装载。主结构与每个有效扩展模块各提供一个独立燃料批次，发电与产热逐批求和，热容量与冷却能力不随模块数扩大。核电站背面、右侧可同时紧贴模块，并经同向完整模块四向扩展，不再使用连接管段；钢／钛／钨钢主结构管道分别允许 1／3／5 个扩展模块（不含主结构），管道不决定单批燃料棒数量。所有模块的管道、燃料棒分别匹配主结构对应等级，燃料棒另须竖直放置；建造与 NEI 共用 `reactor_pipe`／`fuel_rod` 通道。NEI `extra` 提供三级背面示例，不改变世界自动建造范围，详见[核电站模块结构](wiki/development/核电站模块结构.md)。整模组编译和游戏行为待验收。组件方块支持三轴放置，涡轮轴须沿机身长轴，燃料棒在反应堆内须竖直，旧竖直轴须重新横放。

核电站热量超限不立即停机，连续超限后先蒸干堆芯结构水，再将燃料棒方块融为岩浆；计时与重载边界见[项目知识库](wiki/development/项目知识库.md#验证与知识维护)，游戏行为待验收。

热交换根据输入热液自动选择唯一产物：IC2 热冷却液生产过热蒸汽、热超级冷却液生产超临界蒸汽、热钾钠合金复合冷却液生产超超临界蒸汽，NEI 展示三条 1000 L 换热比例预览，不再提供蒸汽模式切换。冷却液属性与换热规则独立，核电站和换热器共用冷却液定义，运行与 NEI 共用已校验的换热注册表；本轮重构尚未编译或游戏验收。涡轮无需 GT 转子，低压轴支持普通／过热／超临界蒸汽，高压轴额外支持超超临界蒸汽，并提供 NEI 比例展示。配置分类、默认值与迁移逻辑以源码及字段旁注释为准，原型数值不是最终平衡。

主控电路板系统、二级纯净水核电路线及独立超超临界蒸汽涡轮机已取消，不列入后续任务；超超临界蒸汽通过新增复合冷却液路线生产。

方块与物品分类注册重构后的 Java 编译及格式检查已通过；完整构建及游戏内配方、性能、NEI、结构、旧存档加载和兼容性仍待验收，编译、格式检查和独立探针不能替代游戏验证。
