## 当前代码交付

核电站、固定结构热交换站和大型普通蒸汽涡轮机已有代码、双语资源与存档实现。三个主机各自持有结构和 GUI，共享 20 tick 处理与 GT 送电链；热交换站支持普通、过热、超临界蒸汽选择，涡轮只处理普通蒸汽。GUI 按主机与模式筛选字段，保留结构和停机诊断。实现与配置见[原型开发指南](wiki/development/第一阶段原型开发指南.md)。

核电站已接入 `27×25×32` 游戏导出结构，使用 8 级统一物品管道外壳，默认单批上限 `256×等级`；I 为严格一进一出流体仓，G 为物品总线、发电仓或可选维护仓区域。几何逐格核对、编译和资源处理已通过；游戏成型与仓室行为尚未验收。

Mixin early / late 基础配置已初始化，尚无实际注入，见 [Mixin 开发指南](wiki/development/Mixin开发指南.md)。没有制造配方、温度／布局机制或最终平衡。已有编译与资源处理验证不代表游戏行为、守恒或兼容性验收；当前工作区无 `src/test/`，早先六项测试仅属历史验证。
