核电站、热交换站和四级蒸汽涡轮机已有原型代码，尚无制造配方；涡轮无需 GT 转子，基础能量为 1.5／4.5／7.5／10.5 EU/L，参数窗口设置 long 型 20 tick 耗汽上限，NEI 展示四条 1000 L 蒸汽比例配方。热交换另展示六条 1000 L 热冷却液转换预览，包含水耗、等量返还、蒸汽产出与结余额度，不参与运行。Java 编译与格式检查通过，不代表游戏行为、NEI、守恒或兼容性验收；当前工作区无 `src/test/`，本轮独立数学探针位于 `dev/validation/HeatExchangePreviewProbe.java`。

低压／高压涡轮轴与四级燃料棒方块已完成基础注册和材质绑定，尚无制造配方。涡轮轴已接入大型涡轮的 26 个同级 G 位置，支持两级结构升级，不改变性能；燃料棒方块已接入核电 52 个同级 D 位置，不改变热容量。大型涡轮结构为 `30×15×15`，主机面朝侧墙外；核电结构为 `29×24×21`，主机偏移 `(2,20,7)`，面朝机房前墙外。新核电结构已完成独立逐格几何检查，完整模组编译与游戏内 NEI／提示／成型未验收。

涡轮 A/B 及 NEI 预览使用真实输出／输入仓，无占位外壳；F 使用 GT 钢块，具体入口见[原型开发指南](wiki/development/第一阶段原型开发指南.md#涡轮大型结构与轴等级)。

六种组件均像原木一样按放置面选择三轴朝向；涡轮轴沿机身长轴横放，建造／预览随主机朝向调整，旧竖直轴须重新横放。燃料棒允许三轴放置，核电默认建造保持竖直；旋转不改变等级或性能。局部 API 编译与独立朝向探针通过，游戏显示未验收。

配置使用 GTNHLib 注解与嵌套配置类，在 `config/thermonuclear.cfg` 中分为通用、核电站、热交换站、大型蒸汽涡轮机四组；旧 `prototype` 保存值按原键迁移，默认值和范围不变，不再生效的旧参数明确标注。字段不初始化，默认值、范围与中文说明写在字段旁；源码布尔开关 `Config.useDevelopmentDefaults` 仅在开发环境覆盖保存值，具体分类、迁移规则与未验证边界见[原型配置](wiki/development/第一阶段原型开发指南.md#原型配置)。
