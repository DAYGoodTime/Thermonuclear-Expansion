核电站、热交换站和大型蒸汽涡轮机已有原型代码，机器控制器尚无制造配方。燃料棒方块已有组装机配方，等级决定核电热容量与最大并行，电源面板限制新批次装载；管道外壳可混用，不再限制批量。组件方块支持三轴放置，涡轮轴须沿机身长轴，旧竖直轴须重新横放。

热交换支持 IC2 热冷却液生产普通／过热蒸汽、热超级冷却液生产超临界蒸汽、热钾钠合金复合冷却液生产超超临界蒸汽，并展示四条 1000 L 换热比例预览；涡轮无需 GT 转子，低压轴支持普通／过热／超临界蒸汽，高压轴额外支持超超临界蒸汽，并提供 NEI 比例展示。配置分类、默认值与迁移逻辑以源码及字段旁注释为准，原型数值不是最终平衡。

主控电路板系统、二级纯净水核电路线及独立超超临界蒸汽涡轮机已取消，不列入后续任务；超超临界蒸汽通过新增复合冷却液路线生产。

当前合并结果未完成完整编译或游戏内配方、性能、NEI、结构及兼容性验收；历史编译、格式检查和独立探针结果不代表当前工作区已验收。
