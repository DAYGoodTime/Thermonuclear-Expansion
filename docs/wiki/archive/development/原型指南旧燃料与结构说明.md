# 原型指南旧燃料与结构说明

> 创建日期: 2026-10-07
> 最后更新: 2026-10-07 11:29
> 作者: DAYGood_Time
> 状态: 已归档

本页保留文档整理时移出的失效表述，仅供追溯；不证明这些行为曾实际实现。当前规则见[原型开发指南](../../development/第一阶段原型开发指南.md)。

| 旧说明 | 当前源码边界 |
| --- | --- |
| 接口位于 `nuclear/FuelRodAdapter.java`，分别支持 IC2 铀、MOX 与 GT 燃料 | 接口在 `api/`；当前 init 仅注册 `GTFuelRodAdapter`，以 `ItemRadioactiveCellIC` 和属性校验识别 |
| 覆盖反应、耐久或乏燃料方法的派生类明确拒绝 | 当前适配器无覆写方法检测，不据此保证第三方行为 |
| 热交换与涡轮主机均位于 `(1,1,0)`，区块检查半径均为 2 | 热交换偏移 `(4,12,1)`、半径 8；涡轮仍为旧值 |
| 核电直发效率较低，供热才显示热缓存及产热字段 | 效率由配置决定；当前两模式均返回热缓存、上限与产热字段 |
| 单根 IC2 铀棒固定按四面反射，示例直发为 250 EU/t | 当前反射附加值仅在工作堆栈数量大于 4 时启用，单根不能直接套用该示例 |
| 核电冷却路径从单一物理输入仓取液 | 当前按所选流体汇总事务输入，不承诺单仓取液 |
| 所有联合输出共用一个 `FluidEjectionHelper` | 公共出口共用 helper，热交换冷却液与蒸汽按 B/F 分组分别模拟 |
| IC2 公式文档称当前适配器固定使用 `4×cells×三角数`，`baseEUt/heatPerCycle` 只表示无邻接基础值，并直接使用 `5×nuclear` | 当前适配器读 GT `sEnergy/sHeat`，工作堆栈大于 4 时追加配置反射脉冲，热值按 cell 取整；主机再应用配置倍率。不模拟真实布局或 MOX 温度，现行规则见原型指南 |

旧表另记载 IC2 铀棒寿命 20000、MOX 寿命 10000，`advDmg` 保存已用周期，铀乏燃料由 `Ic2Items.reactorDepletedUranium*` 引用。它们属于外部核验资料，不作为当前适配能力表；原版公式继续见 [IC2 参考](../../references/IC2-2.2.828反应堆燃料棒公式.md)。
