# GUI 信息拆分前说明

> 创建日期: 2026-10-02 18:26
> 最后更新: 2026-10-02 20:06
> 作者: DAYGood_Time
> 状态: 已被取代

归档原型开发指南中被当前字段拆分替代的显示约定；当前实现见[GUI info 字段与状态样式](../../development/第一阶段原型开发指南.md#gui-info-字段与状态样式)。

旧终端统一追加启动、满负荷、发电仓额定、实际产电、送出、作废与通用流体速率，再追加专机细节。标签与值由两套平行数组提供。2026-10-02 工作区已移除部分标签，但数值数组仍保留原项，形成索引错位风险。

旧开发指南同时保留 `ThermonuclearMultiblockGui` 和已改名的 `PrototypeGui` 两段入口描述，并声称保留 GT 通用处理结果文本。热交换显示配方、蒸汽类型、倍率、周期平均速率与上次提交批次；批次文字由英文单位名和蒸汽 ID 拼接。涡轮另显示冷凝余量，核电供热仍混入发电字段。

这些显示约定已经被按字段名同步、按主机与模式筛选的终端替代。动力仓额定、送出和作废统计仍用于实际送电逻辑；Waila 仍显示产电与送出量，本次没有删除对应处理或存档机制。
