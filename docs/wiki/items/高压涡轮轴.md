## 合成配方

用户确认的 **IV 组装机**配方，尚未注册物品、资源或配方：

| 输入 | 数量 |
| --- | --- |
| EV 马达 | 2 个 |
| 钨钢齿轮箱 | 1 个 |
| 耐热铬铁合金-MA956 锭 | 4 个 |
| 润滑油 | 2000 mB |

相对[低压涡轮轴配方](低压涡轮轴.md#合成配方)替换三种物品材料，数量及润滑油用量不变。输出为高压涡轮轴；输出数量、加工时间、具体 EU/t 及材料／流体 API 标识待确认或实现时核验。

## 设计边界

英文名暂记 `High-Pressure Turbine Shaft`，类别暂记涡轮机械部件。“高压”不等于 HV 电压等级，也未限定超临界／超超临界蒸汽。注册、机器接入、性能、磨损、资源及配套规则均未确定，待定项目与[低压轴设计边界](低压涡轮轴.md#设计边界)相同。
