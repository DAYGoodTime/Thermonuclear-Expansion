# Thermonuclear Expansion 项目知识库

## 项目定位与当前实现

面向 GTNH 的热核与蒸汽能源扩展附属模组，扩展 `IC2 热冷却液 → 热交换 → 蒸汽 → 涡轮 → 电力` 链路，不建立温度或温差模型。[规划原稿](../../../plan/GTNH-Thermonuclear-Expansion-Plan.md)描述目标，`src/` 与构建配置描述实现，两者分开使用。

当前机器能力：

| 机器 | 当前能力 |
| --- | --- |
| 核电站 | 消耗燃料直接发电或供热，支持热量缓存、过热停机与冷却排热。 |
| 热交换站 | 利用热冷却液与蒸馏水生产蒸汽，并返还冷却液。 |
| 大型蒸汽涡轮机 | 消耗不同类型的蒸汽发电并回收蒸馏水，无需 GT 转子，支持设置耗汽上限。 |

机器控制器目前仅供创造模式测试，尚无制造配方；主控电路板、温度／布局机制、维护故障与终局机器尚未实现。

- 新增方块：低压／高压涡轮轴与不同等级的燃料棒方块，分别用于涡轮和核电站结构，支持按放置方向调整轴向；燃料棒方块已有组装机配方。
- 新增流体：超超临界蒸汽，已注册并支持 NEI 展示及涡轮发电，尚无生产路径。

方块与流体资料分别位于 `wiki/blocks/` 和 `wiki/fluids/`；具体实现以源码为准。

| Minecraft / Forge | `1.7.10` / `10.13.4.1614`，`gradle.properties` |
| 模组名 / ID | `Thermonuclear` / `thermonuclear` |
| 根包 | `com.lin.thermonuclear` |
| 构建运行 JDK | `.java-version` 指定 `25` |

| 产品目标 | GTNH `2.9.0`；不等同于当前构建清单或已验收兼容性 |

已有依赖核验记录：GT5U `5.09.54.133`、NewHorizonsCoreMod `2.9.61`（传递 GT `.129` 被替换为 `.133`）、StructureLib `1.4.42`、ModularUI / ModularUI2 `1.3.4` / `2.3.88-1.7.10`、GTNHLib `0.11.51`、UniMixins `0.3.1`。API 以本项目最终选中的 JAR 为准，不照抄来源项目版本；本次文档整理未重新运行依赖解析。

IC2 声明 `2.2.828-experimental:dev`，实际替换为 `curse.maven:ic2-242638:2353971`，JAR 自报 `.827`；本项目燃料 API 核验针对该制品及 RFG 反混淆结果，不代表核验了独立的 `.828` 二进制。

## 目录结构

```text
src/main/
├── java/com/lin/thermonuclear/  # 模组生命周期与配置
│   ├── api/                   # 燃料适配接口
│   ├── loader/                # 内容注册与加载
│   ├── block/                 # 结构组件方块
│   ├── machine/               # 机器逻辑与结构
│   ├── nuclear/               # 核燃料与冷却处理
│   ├── recipe/                # 换热、发电计算与展示配方
│   ├── registry/              # 流体与物品登记
│   ├── gui/                   # 机器界面
│   ├── nei/                   # NEI 集成
│   ├── asm/                   # CorePlugin 入口
│   └── mixins/                # Mixin 加载入口
└── resources/                 # 加载配置、本地化与材质
dev/                           # 结构导出与材质开发工具
docs/                          # 开发知识与专题资料
plan/                          # 产品规划与任务
```

目录说明只覆盖主要职责，不维护逐文件清单；局部实现细节不写入知识库，仅在关键代码处注释。
