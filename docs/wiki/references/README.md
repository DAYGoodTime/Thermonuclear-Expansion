# 参考索引

本目录集中存放本项目的开发参考：外部源码笔记、公式推导与核反应路径。主题文档（`wiki/development/`、`draft/`）只描述当前实现事实，参考路径与外部做法一律指向本目录。

**新增引用只写在这里**：新发现的参考内容追加到已有条目或新建文件，然后在下表登记；主题文档用锚点链接条目，不复制正文。来源范围与只读边界见[迁入资料使用说明](迁入资料使用说明.md)。

- 参考文档如实保留来源与核验范围；外部源码结论不写作本项目验收结论。
- 命令、退出码与测试结果写入[开发验证记录](../../开发验证记录.md)，不写进参考文档。
- 参考文档更新后在新文件与条目内说明适用范围；本索引只维护导航，不记录操作日志。
