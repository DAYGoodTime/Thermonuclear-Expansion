# 参考来源使用说明

> 创建日期: 2026-10-23
> 状态: 长期维护

本文件说明本项目的参考来源范围、只读边界与核验责任。[参考索引](README.md) 按来源列出全部参考文档；主题文档只描述当前实现事实，具体做法与被拒绝的做法集中记录在对应参考文档中。

## 来源范围

开发参考集中在本目录，目前主要覆盖三个参考 Mod：

| 参考来源 | 入口 | 用途 |
| --- | --- | --- |
| GT5U（GT5-Unofficial） | [GT 源码与笔记](GT5U框架笔记.md) | 当前实际依赖的上游 API、机器基类与注册行为 |
| GTNL（GT-Not-Leisure） | [GTNL 参考索引](GT-Not-Leisure参考索引.md) | 功能开发前必查的附属模组实现案例 |
| MessTech | [MessTech 来源原文](MessTech知识笔记.md) | 同一作者的附属模组实现笔记，内容包括世界生成、GUI、Mixin 与跨模组接入 |

另有外部公式与策划依据：[IC2 反应堆公式](IC2-2.2.828反应堆燃料棒公式.md)、[Mekanism 裂变公式](Mekanism裂变反应堆发热与冷却剂公式.md)、[稀土核反应路径](稀土元素中子捕获与衰变路径.md)、[TST 分片结构](TST大型机器分片总结.md)。

## 只读边界

- 参考仓库与参考原文只读：不修改参考仓库，不自动添加构建依赖，不复用其机器 ID、注册名或平衡数值，不把参考文档当作本项目验收结论。
- GT5U 以本项目实际解析的依赖为准；从笔记或旧快照读到的版本、签名与数值，使用前必须对照当前选中的 JAR 重新核对。
- MessTech 与 GTNL 的笔记保留原始语言与写法，未逐条复验。其中的参考数值不属于本项目平衡，类名存在不代表可调用方法存在。

## 核验责任

- 实现前说明查到的参考路径、可复用思路与版本差异；参考不可访问时明确说明，不假装已完成核验。
- 新发现的参考内容只追加到本目录的对应文件或新建条目，并在[参考索引](README.md) 登记；主题文档用锚点指向条目，不复制正文。
- 命令、退出码与测试结果属于[开发验证记录](../../开发验证记录.md)，不写入参考文档。
