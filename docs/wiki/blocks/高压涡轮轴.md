# 高压涡轮轴

> 创建日期: 2026-10-07
> 作者: OpenCode
> 状态: 基础方块、材质、涡轮结构等级、蒸汽准入限制及组装机配方已实现

## 合成配方

已注册的 **IV 组装机**配方，输出为可放置的涡轮轴方块：

| 输入 | 数量 |
| --- | --- |
| EV 马达 | 2 个 |
| 钨钢齿轮箱 | 1 个 |
| 耐热铬铁合金-MA956 锭 | 4 个 |
| 润滑油 | 2000 mB |

相对[低压涡轮轴配方](低压涡轮轴.md#合成配方)替换三种物品材料，数量及润滑油用量不变。输出 1 个高压涡轮轴，耗时 10 秒（200 tick），使用 `TierEU.RECIPE_IV`（7680 EU/t）。

配方由 `loader/RecipeLoader.register()` 注册到组装机配方表，在 `CommonProxy.loadComplete` 加载；输入引用为 `ItemList.Electric_Motor_EV`、`ItemList.Casing_Gearbox_TungstenSteel`、`MaterialsAlloy.INCOLOY_MA956.getIngot(4)` 与 `Materials.Lubricant.getFluid(2000)`。已核验缓存 GT5U `5.09.54.133` API，尚未完成本轮完整编译或游戏配方验收。

## 设计边界

英文名为 `High-Pressure Turbine Shaft`，类别为涡轮轴方块，不是独立轴类物品图标。“高压”不等于 HV 电压等级。已接入大型蒸汽涡轮的 26 个 G 位置，作为等级 2，必须全部使用高压轴，不能与低压轴混装。支持普通、过热、超临界和超超临界蒸汽；相比低压轴，升级收益为解锁超超临界蒸汽发电，不额外改变吞吐、单位蒸汽能量或磨损。选汽、混合输入及降级规则见[低压轴设计边界](低压涡轮轴.md#设计边界)。

## 当前实现

注册名 `thermonuclear:high_pressure_turbine_shaft`，独立方块，默认元数据 0；引用为 `BlockLoader.highPressureTurbineShaft`。使用 `turbine_shaft_side_4.png` 与 `turbine_shaft_top_bottom_4.png`，运行路径在 `assets/thermonuclear/textures/blocks/turbine_shaft/`。注册时机、创造模式入口、提示、堆叠及基础采集／渲染属性与[低压轴](低压涡轮轴.md#当前实现)相同，不因名称增加性能或电压效果；未运行游戏验收。

高压轴与低压轴共用 `BlockAxialMachineComponent`，按放置面选择 Y／X／Z 轴（元数据 0／4／8），端面与侧面 UV 随朝向变化；掉落及中键物品仍为元数据 0。`MTELargeSteamTurbine` 以 `ofBlocksTiered` 识别等级 2，`turbine_shaft` 建造通道数量 2 及以上选择高压轴；26 个轴须沿机身长轴放置，常规结构为横向，检查、提示与创造／NEI 建造随主机 `ExtendedFacing` 推导世界方向。旧竖直轴须手动重新横放。规则与验证边界见[低压轴](低压涡轮轴.md#当前实现)，完整模组编译与游戏行为未验收。

设计参考 GT++ 的 `Turbine Shaft` 贴图，当前文件与授权边界见[材质工作目录](../../../dev/texture-workbench/README.md)。
