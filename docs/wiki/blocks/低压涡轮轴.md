## 合成配方

用户确认的 **HV 组装机**配方，输出为可放置的涡轮轴方块；方块及资源已注册，配方尚未注册：

| 输入 | 数量 |
| --- | --- |
| MV 马达 | 2 个 |
| 不锈钢齿轮箱 | 1 个 |
| 耐热 903 双重板 | 4 个 |
| 润滑油 | 2000 mB |

输出为低压涡轮轴；输出数量、加工时间、具体 EU/t 及材料／流体 API 标识待确认或实现时核验。

## 设计边界

英文名为 `Low-Pressure Turbine Shaft`，类别为涡轮轴方块，不是独立轴类物品图标。“低压”是机械用途描述，不等于 LV 电压等级。已接入大型蒸汽涡轮的 26 个 G 位置，作为等级 1；全部轴须同级，可整体替换为[高压涡轮轴](高压涡轮轴.md)升级至等级 2。当前仅处理普通蒸汽，轴等级不改变吞吐／效率／输出、不替代 GT 转子；性能、耐久及阶段平衡尚未确定。

## 当前实现

- 注册名 `thermonuclear:low_pressure_turbine_shaft`，独立方块，默认元数据 0；引用为 `BlockLoader.lowPressureTurbineShaft`。
- `CommonProxy.preInit` 调用 `loader/BlockLoader.register()`；创造模式的建筑方块页提供物品，堆叠上限沿用 `ItemBlock` 默认 64，并显示双语名称、品牌及轴等级／同级结构要求。
- 材质采用用户交付的 `turbine_shaft_side_1.png` 与 `turbine_shaft_top_bottom_1.png`，运行路径在 `assets/thermonuclear/textures/blocks/turbine_shaft/`。
- 默认完整立方体、固定竖直方向；四侧共用 side，上下共用 top_bottom。使用铁材质、金属脚步声、硬度 5、抗爆设置 10、一级镐采集；这些是基础放置属性，不是涡轮性能或最终平衡。
- 无 TileEntity、燃料存储、GT 转子替代或机器性能效果；`MTELargeSteamTurbine` 以 `ofBlocksTiered` 识别，`turbine_shaft` 建造通道选择等级。完整结构规则见[原型开发指南](../development/第一阶段原型开发指南.md#涡轮大型结构与轴等级)，独立几何／轴判定通过，完整模组编译与游戏行为未验收。

设计参考 GT++ 的 `Turbine Shaft` 贴图，当前文件与授权边界见[材质工作目录](../../../dev/texture-workbench/README.md)。
