# 低压涡轮轴

> 创建日期: 2026-10-07
> 作者: OpenCode
> 状态: 基础方块、材质、涡轮结构等级、蒸汽准入限制及组装机配方已实现

## 合成配方

已注册的 **HV 组装机**配方，输出为可放置的涡轮轴方块：

| 输入 | 数量 |
| --- | --- |
| MV 马达 | 2 个 |
| 钢齿轮箱 | 1 个 |
| 耐热 903 双重板 | 4 个 |
| 润滑油 | 2000 mB |

输出 1 个低压涡轮轴，耗时 10 秒（200 tick），使用 `TierEU.RECIPE_HV`（480 EU/t）。GT5U `5.09.54.133` 不提供原文所写的不锈钢齿轮箱，用户已确认使用钢齿轮箱。

配方由 `loader/RecipeLoader.register()` 注册到组装机配方表，在 `CommonProxy.loadComplete` 加载；输入引用为 `ItemList.Electric_Motor_MV`、`ItemList.Casing_Gearbox_Steel`、`GGMaterial.incoloy903.get(OrePrefixes.plateDouble, 4)` 与 `Materials.Lubricant.getFluid(2000)`。已核验缓存依赖 API，尚未完成本轮完整编译或游戏配方验收。

## 设计边界

英文名为 `Low-Pressure Turbine Shaft`，类别为涡轮轴方块，不是独立轴类物品图标。“低压”是机械用途描述，不等于 LV 电压等级。已接入大型蒸汽涡轮的 26 个 G 位置，作为等级 1；全部轴须同级，可整体替换为[高压涡轮轴](高压涡轮轴.md)升级至等级 2。无需 GT 转子，低压轴仅支持普通、过热和超临界蒸汽，不能使用超超临界蒸汽发电；轴等级不额外改变吞吐或单位蒸汽能量。

运行选汽在消费流体前调用 `SteamTurbineFuel.supportsShaftTier()`，跳过不允许的蒸汽；仅输入超超临界蒸汽时提示需要高压轴，不消耗该流体。有其他可用蒸汽时仍可处理允许的种类。发电 tick 复查等级，结构降级后停止超超临界蒸汽预付批次，不回退或复制已消费的蒸汽。

## 当前实现

- 注册名 `thermonuclear:low_pressure_turbine_shaft`，独立方块，默认元数据 0；引用为 `BlockLoader.lowPressureTurbineShaft`。
- `CommonProxy.preInit` 调用 `loader/BlockLoader.register()`；创造模式的建筑方块页提供物品，堆叠上限沿用 `ItemBlock` 默认 64，并显示双语名称、品牌及轴等级／同级结构要求。
- 材质采用用户交付的 `turbine_shaft_side_1.png` 与 `turbine_shaft_top_bottom_1.png`，运行路径在 `assets/thermonuclear/textures/blocks/turbine_shaft/`。
- 完整立方体，`block/BlockAxialMachineComponent` 按点击面法线选择轴向：上下放置为 Y（元数据 0），东西为 X（4），南北为 Z（8）；两端共用 top_bottom，其余面使用 side。沿用原版原木渲染类型 31，侧面 UV 随轴向旋转，不新增 PNG 或客户端渲染器。普通掉落、精准采集和中键取块均回到物品元数据 0，重新放置时重新选择方向。
- 使用铁材质、金属脚步声、硬度 5、抗爆设置 10、一级镐采集；这些是基础放置属性，不是涡轮性能或最终平衡。
- 无 TileEntity 或燃料存储，蒸汽准入效果由机器实现；`MTELargeSteamTurbine` 以 `ofBlocksTiered` 识别，`turbine_shaft` 建造通道选择等级。26 个轴须沿机身长轴放置，常规水平结构中为横向；检查、提示、创造建造与 NEI 预览由 `defer` 按当前 `ExtendedFacing` 推导世界轴向。旧竖直轴须手动重新横放，不自动改写存档。
- 独立方法探针覆盖六面放置、三轴图标映射、同级／朝向判定与真实 StructureLib 的 96 种朝向；组件注册与动态轴元素通过缓存 API 的局部 `javac` 编译，不等于完整模组编译或游戏渲染验收。

设计参考 GT++ 的 `Turbine Shaft` 贴图，当前文件与授权边界见[材质工作目录](../../../dev/texture-workbench/README.md)。
