# 新增内容设计草稿

本目录存放新增方块、流体和物品的早期设计，按类型分为 `blocks/`、`fluids/`、`items/`。

## 与正式文档的边界

- 新增方块、流体或物品在动手实现前，先在本目录写一份设计，至少写明名称与注册名、用途、来源或制造方式、与其他机器的接入关系、关键数值和实现边界。
- 设计随实现推进就地补充，直到内容定稿。定稿指名称、注册名、用途、配方材料和关键数值均已确定，不再预期改动。
- 设计完善、内容定稿后，该条目的设定即冻结；后续实现完善功能、修复缺陷、调整内部实现均不再修改本目录内的设计文档。与设计不一致的改动先确认设计变更，再同步文档。
- 本目录文档反映设计意图，不保证与源码一致；当前实际行为以源码、[项目知识库](../wiki/development/项目知识库.md) 与[开发验证记录](../开发验证记录.md) 为准。
- 本目录不作为项目事实来源，日常开发默认不读取；仅在新增内容设计、核对原始设计意图或排查与设计不符的实现时查阅。
